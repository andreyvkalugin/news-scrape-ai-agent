```

│     │                                                        │

│           │ rewritten_queries → в AgentState                 │
│           ▼                                                  │
│  ┌──────────────────────────────────────────┐ ◄──────┐       │
│  │            react_agent                   │        │       │
│  │                                          │        │       │
```

### используемая схема гибридного поиска (Hybrid Search)
**два метода поиска одновременно**:

```
  Запрос пользователя
         │
         ├──────────────────────────────────────────┐
         │                                          │
         ▼                                          ▼
  GigaChat Embeddings                         BM25Okapi
  (запрос → вектор)                      (токенизация запроса)
         │                                          │
         ▼                                          ▼
  ChromaDB.MMR(k=12)                    BM25-индекс по всем
  ┌───────────────────────┐             документам ChromaDB
  │ Relevance:            │             ┌──────────────────────┐
  │  Д1: 0.91             │             │ TF-IDF оценки:       │
  │  Д2: 0.87             │             │  Д3: 14.2  ← топ     │
  │  Д3: 0.85             │             │  Д1: 11.8            │
  │  ...                  │             │  Д5: 9.4             │
  │ Diversity (lambda=0.7)│             │  Д7: 8.1             │
  │  убирает дубликаты    │             │  ...                 │
  └───────────────────────┘             └──────────────────────┘
         │ 12 документов                       │ 12 документов
         │                                     │
         └──────────────────┬──────────────────┘
                            │
                            ▼
                    RRF-слияние
          ┌─────────────────────────────────────┐
          │  score(Д) = 1/(60+rank_sem)         │
          │           + 1/(60+rank_bm25)        │
          │                                     │
          │  Д1: 1/61 + 1/62 = 0.0325  ← 1-й    │
          │  Д3: 1/63 + 1/61 = 0.0322  ← 2-й    │
          │  Д2: 1/62 + 0    = 0.0161  ← 3-й    │
          │  Д5: 0    + 1/63 = 0.0159  ← 4-й    │
          └─────────────────────────────────────┘
                            │
                            ▼
                    топ-6 документов
                    (разнообразных, без дублей,
                     найденных как по смыслу,
                     так и по ключевым словам)
                            │
                            ▼
                          Агент
```
